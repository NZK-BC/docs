# Token

## Token 是什么？
token 是您在洛谷保存站的唯一识别凭据，用于登录保存站账号，保护您的账户安全。

## 如何申请 Token

请前往 [申请界面](https://www.luogu.me/token/apply)，输入您的洛谷 UID，和用于验证的剪切板 ID。

## 注意事项

- 需要提供有效的剪贴板 ID 作为身份验证，剪贴板内容应为 `lgs_register_verification`（无多余空格或字符,建议直接复制粘贴）。请一定不要泄露您的验证剪切板 ID，最好是在申请 Token 后删除。
- 申请的凭据只会显示一次，请注意保存，重复申请将重新申请凭据。
- 本凭据将作为您在洛谷保存站识别身份的唯一凭据，请不要丢失。
- 如有滥用行为，我们有权撤销您的 Token 使用权。
- token 若被盗用，请立即重新申请，旧 Token 会被删除。
